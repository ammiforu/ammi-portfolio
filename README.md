# Ammi Reddy Tetala — Premium 360° Editorial Portfolio

An interactive, high-performance personal portfolio built for **Ammi Reddy Tetala** (Enterprise IT Manager & Solutions Developer). Designed with a luxury editorial aesthetic, ultra-smooth Lenis scroll synchronization, a scroll-driven 360° interactive hero turntable centerpiece, and showcasing deep expertise in enterprise integration (IBM Sterling B2B Integrator, OpenText BizManager, IBM MQ), database infrastructure (PostgreSQL, Oracle), and local AI deployment (Dell Micro PC Ollama clusters).

## 🚀 Key Features

- **Centerpiece 360° Interactive Hero Turntable**: High-precision scroll-synchronized 360° rotation (0° to 360°) mapped to scroll progress with sub-frame linear interpolation.
- **Luxury Editorial Dark Mode**: Deep obsidian canvas (`#08080a`), warm champagne accents (`#e2c392`), editorial typography (`Syne`, `Plus Jakarta Sans`), thin borders, and custom interactive cursor.
- **Enterprise Engineering Showcase**:
  - *Enterprise Database Migration* (Excel -> PostgreSQL + Web Dashboard + OAuth SSO)
  - *Automated Video Production Pipeline* (Remotion + Claude + DaVinci + Pollinations AI)
  - *AI-Powered Personal Portfolio* (Firebase + Gemini 3.6 Flash + GitHub Sync)
  - *Enterprise Automation Suite* (IBM MQ monitoring, BlankLineFixer.sh, csv_merger.sh)
- **Technical Capabilities**: Interactive typography grid for integrations, databases, DevOps infrastructure, and local LLMs.
- **Media Network Integration**: YouTube Telugu-language channel portfolio (@ViswaDarshiniUsa, AMMI EXPLAIN).
- **SEO & Performance**: Zero layout shifts, high DPR canvas rendering, metadata tags, and sub-second production bundle builds.

## 🛠 Tech Stack

- **Framework & Language**: React 19, TypeScript, Vite, Tailwind CSS v4
- **Animation & Motion**: GSAP, ScrollTrigger, Lenis Smooth Scroll, Framer Motion
- **Icons**: Lucide React & Custom Brand SVG Icons

## ⚡ Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

```
